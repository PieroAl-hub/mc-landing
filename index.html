Cómo conectarte

  1. Abre Minecraft Java Edition
  2. Ve a Multijugador → Agregar Servidor
  3. Pon la IP y puerto que te hayan asignado
  4. ¡Listo! Disfruta

Instalar Mods / Plugins

Si el servidor usa Forge (mods):

  • Descarga los mods .jar (CurseForge, Modrinth)
  • Conéctate por SFTP (te damos los datos)
  • Sube los archivos a la carpeta mods/
  • Reinicia el servidor

Si el servidor usa Paper/Spigot (plugins):

  • Descarga los plugins .jar (SpigotMC, Polymart)
  • Sube a plugins/ por SFTP
  • Reinicia el servidor

Minijuegos (Bedwars, Skywars...)

  1. El server debe ser Paper (no vanilla)
  2. Descarga el plugin (ej: BedWars1058)
  3. Súbelo a plugins/ por SFTP
  4. Reinicia y configura con /bw setup

Plugins populares: BedWars1058, SkyWarsReloaded, TheBridge, MurderMystery

Acceso SFTP

Para subir archivos grandes o editar configs:

  • Te damos usuario, contraseña y puerto SFTP
  • Conéctate con FileZilla, WinSCP o cualquier cliente
  • Ahí puedes subir mods, plugins, configs, etc.
